# GravityShift

> Гравитация — твоё оружие. Переворачивай бой.

**GravityShift** — динамичный [шутер от первого/третьего лица], где ты управляешь направлением гравитации и притягиваешь цели к себе. Стены и потолок — не преграда, а тактические позиции. Враг не ждёт атаки снизу, если ты атакуешь с неба. Или с потолка.

##  Управление

| Действие | Клавиша |
|---|---|
| Движение | `W` `A` `S` `D` |
| Прыжок / отрыв | `Space` |
| Смена гравитации | `Q` / `E` (поворот по кругу) или `Shift` (мгновенный переворот) |
| Гравитационная пушка | `ЛКМ` (притянуть цель) |
| Стрельба | `ПКМ` |
| Перезарядка | `R` |
| Спринт | `Shift` |
| Пауза | `Esc` |
